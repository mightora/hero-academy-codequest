# Hero Academy game instructions

Read the [shared standard](https://github.com/mightora/hero-academy/blob/main/HERO_ACADEMY_DEVELOPMENT_STANDARD.md) and the local brand guide before editing.

The family login and settings live at https://heroacademy.app; identity, permissions, cloud saves, activity and Hero XP use the existing ChoreQuest API. Preserve local play, local profiles and backups. Use the vendored `academy-client.js` and the adapter in the main application; never pass adult cookies to a game. Follow the hub standard when adding levels, milestones or a new game.
